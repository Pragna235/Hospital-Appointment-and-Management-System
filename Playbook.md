# Backend

* Import the 5 microservices and 1 server in the `Spring Tool Suite / Eclipse`
* Run the microservices as `Spring Boot Application`
* Make sure the database connection information is right in all the `application.properties` file
* Once run, make sure to register hardcode doctors using postman
* Then run the `doctoravailability scheduler` once for all the registered doctors

# Frontend

* Import the frontend code in `Visual Studio`
* Go to the project folder and run `npm start`
